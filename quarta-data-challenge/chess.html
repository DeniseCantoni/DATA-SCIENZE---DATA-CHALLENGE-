TERZA DOMANDA

An interesting property of Elo’s ratings is that the sum of all player ratings is always 0. Formally show this property.

Per dimostrare che la somma degli r dei giocatori è sempre 0 parto dall’inizio.

1. Condizione iniziale: All’inizio, per definizione, i punteggi Elo di tutti i giocatori sono impostati a \(0\): \[r_i^{(0)} = 0 \quad \text{e} \quad r_j^{(0)} = 0 \implies \sum r^{(0)} = 0\]

2. Aggiornamento: Dopo una partita tra il giocatore \(i\) e il giocatore \(j\), i nuovi punteggi vengono calcolati aggiungendo una variazione \(\Delta r\) ai punteggi precedenti: \[r_i^{(1)} = r_i^{(0)} + \Delta r_i^{(0)}\] \[r_j^{(1)} = r_j^{(0)} + \Delta r_j^{(0)}\]

dove le variazioni sono definite da: \[\Delta r_i^{(0)} = \kappa (s_{i,j} - \mu_{i,j})\] \[\Delta r_j^{(0)} = \kappa (s_{j,i} - \mu_{j,i})\]

3. Calcolo della somma delle variazioni (\(\Delta r\)): Sommando le variazioni dei due giocatori coinvolti nella partita: \[\Delta r_i^{(0)} + \Delta r_j^{(0)} = \kappa (s_{i,j} - \mu_{i,j}) + \kappa (s_{j,i} - \mu_{j,i})\] \[\Delta r_i^{(0)} + \Delta r_j^{(0)} = \kappa \big[ (s_{i,j} + s_{j,i}) - (\mu_{i,j} + \mu_{j,i}) \big]\]

Sfruttando le proprietà note del sistema:

\[s_{i,j} + s_{j,i} = 1\]

\[\mu_{i,j} + \mu_{j,i} = 1\]

Sostituendo queste identità nell’equazione: \[\Delta r_i^{(0)} + \Delta r_j^{(0)} = \kappa (1 - 1) = \kappa \cdot 0 = 0\]

4. Somma dei punteggi aggiornati: Sommando i punteggi finali dopo la partita: \[r_i^{(1)} + r_j^{(1)} = \big( r_i^{(0)} + r_j^{(0)} \big) + \big( \Delta r_i^{(0)} + \Delta r_j^{(0)} \big) = 0 + 0 = 0\]

5. Step successivi: Nelle partite successivo il valore della somma degli r sarà comuqnue 0 in quanto la somma dei delta=0 e la somma dei rating del turno precedente è 0 per la simostrazione del punto successivo

In generale a ogni partita il rating assegnato al giocatore che vince è uguale a quello tolto al giocatore che perde.

QUARTA DOMANDA

Write a function that computes the player Elo rating (set ζ=400 and κ=25) (Hint: take advantage of the 0-sum property to optimize the code). Obserse its distribution: why is different from the point distribution? Verify the 0-sum property for Elo’s ratings

calcola_elo <- function(data, C = 400, k = 25) {
  
  #creo vettore con id giocatori e punteggio iniziale di elo = 0
  giocatori <- unique(c(data$White, data$Black))
  elo <- setNames(rep(0, length(giocatori)), giocatori)
  
  # Aggiorno il rating partita per partita
  for (i in 1:nrow(data)) {
    
    bianco <- as.character(data$White[i])
    nero <- as.character(data$Black[i])
    
    # Punteggio effettivo del Bianco
    s_bianco <- data$Score[i]
    
    # Punteggio atteso del Bianco
    atteso_bianco <- 1 / (1 + 10^((elo[nero] - elo[bianco]) / C))
    
    # Variazione del rating
    delta <- k * (s_bianco - atteso_bianco)
    
    # Aggiorno i rating dei due giocatori
    elo[bianco] <- elo[bianco] + delta
    elo[nero] <- elo[nero] - delta
  }
  
  return(elo)
}

grafico_correlazione

Il grafico mostra una correlazione positiva abbastanza forte tra i due punteggi, confermata anche dal coefficiente di pearson= 0,72. Quindi un giocatore con uno Score totale elevato tende ad avere un rating di elo elevato. Tuttavia, i due punteggi non sono perfettamente correlati, come si nota dal grafico.

La differenza tra i due punteggi dipende da come vengono calcolati: il punteggio totale è dato dalla somma dei punti, mentre il rating Elo viene aggiornato tenendo conto anche del rating dell’avversario. Di conseguenza, una vittoria contro un avversario con un rating elevato può comportare un guadagno Elo maggiore rispetto a una vittoria contro un avversario più debole.

I top player calcolati ocn i due punteggi diversi possono quindi essere diversi in base al metodo di calcolo.
